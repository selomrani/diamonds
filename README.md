# Diamond Price Prediction

A machine learning project to predict diamond prices based on physical and geometric characteristics using Scikit-Learn.

## Overview
This repository contains an end-to-end regression pipeline for predicting diamond prices from carat weight, cut, color, clarity, and physical dimensions.

## Project Structure
- `notebooks/`: Jupyter notebooks with exploratory data analysis (EDA) and model development.
- `diamonds.csv`: Diamond dataset containing 53,940 records.
- `requirements.txt`: Python package dependencies.

## Setup
Install dependencies:
```bash
pip install -r requirements.txt
```
